Wi-Fi

Network-

Sidecar uses one network at a time: Connect and save stores the network and restarts Sidecar on Wi-Fi (the sound stops for a few seconds; Ethernet is unused while it is on Wi-Fi). If it is not connected within 90 s, the previous setting comes back and Sidecar restarts on it (Ethernet, if Wi-Fi was off), so a wrong password cannot lock you out. This page follows to the Wi-Fi address at sidecar.local when this computer is on that network. The password is stored only as the network's key, never shown again; this page has no login yet, so anyone on the same network can change these settings.

Sound

Never send channels 10/11 back into the Rytm through Overbridge (computer audio, a mixer loop): that is a feedback loop.

Display

100 %

Brightness dims the picture, not the backlight (the panel's backlight has no software control). Both are kept on the card (/.rytm/display.txt); screensaver= / brightness= in cmdline.txt override them at boot.

Send FX

What the Rytm's kit sets: each FX's type, where it returns (PRE on 2/3, POST on 0/1) and the 12 tracks' send levels.

LFOs

Eight LFOs on the Sidecar's voices (V1..V8: any parameter) or its send FX (FX1 / FX2 P2..P5), on top of the Rytm's value; the value comes back when the LFO stops. Saved per kit, as the Rytm's own LFOs (switched with the Rytm's kit); the same on the Rytm's LFO page (TRK + YES).

Channels

One WAV a channel (mono; Master and the FX returns as stereo files), all starting on the same frame and the same length, so they line up in a DAW. Meters show the peak of the last second while armed or recording.

The pool is the project's (the Rytm's current project: /.rytm/pools/<project>.txt, as on the Teensy). DSP SAMPLE's SMP knob and user machines (API 2) pick slot 1..127; the Rytm gets the table at once. Pick a .wav below to put it into the slot above.

JUNO list

PATPatch

/.rytm/juno/<project>.txt. Save current stores the patch a JUNO voice plays now with its six knobs (CUT RES ENV ATK DEC REL) as they are, into the first empty slot.

6-OP FM list

PATVoice

/.rytm/fm/<project>.txt (a bank's MD5 and voice per slot). While the list is empty, PAT picks the 96 ROM voices; once it has a voice, PAT picks from the list.

User machine presets

/PRESETS/<machine id>/: <name>.txt ("P<n> <value>" lines) and the machine's own preset files; the slot's PRE knob picks them in name order, as on the Teensy. Save current writes the knobs the slot's last voice plays now.

Files

Go to

Drop files or folders on the list to upload them into this folder (folders whole, with their subfolders; .DS_Store and ._ files are left out). Uploads go one at a time in small pieces: the page runs on core 0 with the network, USB and the card, apart from the audio (render cores 1 and 2, control core 3). 🔒 marks boot files and the restore backup (read-only); Samples, Plugins and .rytm themselves are kept (their contents can change).

About

      

      
Sidecar | Expander, a sound engine beside the drum machine. Core 0 runs the network (this page),
        USB (Overbridge, USB-C) and the card; cores 1 and 2 render the voices and the send FX; core 3 is the control
        core (MIDI, machines, loading). The page never waits on the audio: a request is answered from what the
        cores last published.
